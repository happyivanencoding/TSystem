# Handoffs

大任务完成后，在本目录新增一份 handoff。小 bugfix、纯查询和不影响后续接手的一次性任务不强制新增。

## 命名建议

```text
YYYY-MM-DD_short-topic.md
```

## 模板

```markdown
# 任务标题

## 日期

YYYY-MM-DD

## 任务目标

简述用户要达成的结果。

## 修改文件

- `path/to/file`：做了什么。

## 关键决策

- 决策和原因。

## 验证方式

- 命令、检查项或产物路径。

## 产物路径

- 如无正式产物，写“无”。

## 风险/未完成

- 如无，写“无已知风险”。

## 下次建议

- 下一位接手者先看哪里、先跑什么。
```
